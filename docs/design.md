# macOS 设计记录

当前版本为 0.3.4。网络能力需求、设计与任务以 `../specs/network-v2/` 为准；系统过滤及抓包的真实验收边界见 `network-v2-verification.md`。下文先记录当前界面，再保留 0.1.0 的历史能力范围。

## 0.3.4 当前界面

视觉方向为中性灰、系统材质和克制的蓝色强调。玻璃只用于侧栏选中态、顶部状态胶囊和确实与内容重叠的标题区域，不给普通内容卡叠加模糊。侧栏、标题栏和内容区使用系统材质与发丝分隔线建立层级。

侧栏品牌区位于窗口标题栏下方。首页、网络体检、保护为主导航；设置固定在侧栏底部，选中后子菜单在按钮上方展开，不改变按钮的底部锚点。折叠态保留品牌徽标和导航图标，设置仍在底部。

首页按“状态与下一步”组织，而不是拼接统计数字：

- 顶部概览显示监控状态、自检摘要、固定目标、代理出口、TUN 路由、检查时间和主操作。
- Claude 保护范围显示 Desktop/Code 的启用状态、安装与进程状态、异常动作和最近异常。
- 最近出口体检复用网络体检结果，显示结论、主出口、IPv6、服务可达性、出口漂移和自动体检节奏。
- 最近变化显示最近四条运行记录，并跳转到设置中的完整记录。

网络体检首屏先给结论和服务摘要，再给报告操作和高级选项。报告操作只包含导出与清除；第三方 IP 情报作为独立高级设置。详细证据与历史保留单一入口，展开后分为“网络证据”和“上下文与历史”，避免把排查信息碎片化为多个一级导航。

应用图标为深灰毛玻璃圆角方形，使用亮色边缘、内部高光和细颗粒形成材质感；中心为放大的半填充盾牌。图标由 `scripts/make-icon.swift` 生成全部 Retina 尺寸，不使用外部位图。

## 0.1.0 历史范围

用户要求：适配 FlClash；Claude 桌面与 Claude Code 分别可选；自动识别和自检查。

采用 macOS 14+ SwiftUI 菜单栏应用，保留常规主窗口。设置仅保存在本应用 UserDefaults。自检查不修改 FlClash、系统代理、路由或 Claude 数据。

自检查读取：FlClash 安装/运行状态、Claude 桌面安装/运行状态、Claude Code 常见安装路径和同用户进程、系统 HTTPS 代理、两个公网目的地的路由，以及系统代理/不显式代理两路出口。支持用户填写固定 IPv4 或 IPv6；目标 IP 不从网络结果静默学习。空目标可展示检测结果但不能开启监控。

保护选项各自启用。默认异常动作“仅提醒”；用户可选择“请求退出所选 Claude 进程”。选择退出动作并点击开启监控即是对后续本机动作的授权。开发验证仅执行只读诊断，绝不自动开启用户的保护或结束现有进程。

状态机：未监控 → 检查成功后监控 → 条件失败后异常锁定。异常状态不会因网络恢复自动解除；重新检查后点击开启监控才能恢复。停止监控取消未来动作。任何配置改变使当前监控失效。每轮结果带配置快照，旧结果不得重新开启监控。监控任务不依赖窗口存活。

进程范围：同 UID，桌面进程必须落在已验证 bundle 的目录；Code 必须是明确的原生 Claude 可执行路径，或 Node 的明确 Anthropic CLI 脚本。通用 node、终端和编辑器不会被整体结束。结束前重新核对 PID、启动时间、可执行路径，降低 PID 复用风险。退出动作发送 SIGTERM 并报告结果，不宣称已断网。

本版不实现系统级网络扩展/防火墙，不宣称零泄漏；不提供节点切换、环境伪装、浏览器清理或密码删除。自动发现的其他 VPN utun 路由仅是 TUN 路由证据，不单独证明归属于 FlClash。界面明确这些边界。

验证：Swift 编译；IP 解析、路由判定、两路出口一致性、保护范围、PID 身份以及锁定/恢复的单元测试；只读本机诊断；应用打包与签名检查；界面启动检查。交付完整源代码、可运行 .app 和说明。
