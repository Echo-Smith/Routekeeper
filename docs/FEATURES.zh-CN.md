<h1 align="center">Routekeeper 功能说明</h1>

<p align="center">
  <a href="../README.md">English</a> |
  <a href="../README.zh-CN.md">简体中文</a>
</p>

Routekeeper 是一款原生 macOS 网络体检、代理出口核验与 Claude 运行环境工具。本文以当前代码实现为准，完整列出应用页面、核心能力、实验性边界和当前构建限制。

> [!NOTE]
> 当前文档对应 Routekeeper **0.3.12（构建 22）**。源码公开、仅限非商业用途；
> 实验功能和界面仍可能继续调整。

## 状态说明

| 状态 | 含义 |
| --- | --- |
| 已实现 | 当前代码中可用，按界面条件正常提供 |
| 实验性 | 已实现，但底层接口、兼容性或安全边界存在已知风险 |
| 条件可用 | 需要外部软件、用户授权、系统权限或特定运行环境 |
| 当前不可用 | 源码存在，但当前 ad-hoc 构建无法启用 |

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| Claude 保护开关 | 已实现 | 安装并检测到客户端后可用 |

Routekeeper 不会自动修改代理客户端、订阅、节点或系统代理配置。

| 手动固定地区 | 实验性 | 出口变化不会自动覆盖固定设置 |
| 无效配置标识 | 实验性 | 红色标出无效时区或语言 |
| 自动修复 | 实验性 | 使用有效出口或系统默认值修复配置 |
| 上游代理 | 实验性 | 支持本机 HTTP CONNECT、SOCKS5 和混合入口 |

## 当前限制

- 当前支持 macOS 14 及以上系统。
- 当前交付构建仅支持 Apple Silicon。
- 当前为 ad-hoc 签名开发预览，尚未 Developer ID 签名和 Apple 公证。
- Network Extension 指定进程过滤在当前构建不可用。
- 沙箱依赖已弃用的 `sandbox-exec`，不等同于虚拟机。
- 沙箱不能隐藏网卡名称、本机地址、路由和 DNS 解析器等宿主网络元数据。
- 沙箱不伪装硬件销售地区，也不保证设备指纹或服务端风控结果。
- 沙箱不会自动把工作副本覆盖回原项目。
- Git 补丁不会自动 commit 或 push。
- Routekeeper 不会自动修改代理客户端或订阅。
- 第三方 IP 地区信息只在用户主动请求时获取。
- 本地推断的出口地区与 Anthropic 服务端实际地区判断可能不同。
- 隔离环境可能限制 Claude Code 的部分云端连接器。
- 检查结果只代表当前 Mac 和当前网络会话取得的证据。
